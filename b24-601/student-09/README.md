# Рабочая директория `student-09`

Директория предназначена для постоянной работы студента группы `b24-601` с идентификатором `student-09`.

## Параметры

- Группа: `b24-601`.
- Идентификатор студента: `student-09`.
- Рабочая ветка: `student/b24-601/student-09`.

## Правила работы

Размещайте учебные файлы только в этой директории, если преподаватель не указал иной порядок. Не изменяйте директории и ветки других студентов.

Для отчётных заданий используйте отдельно подготовленные ветки `student-submission/<работа>/b24-601/student-09` и следуйте инструкции преподавателя по созданию Pull Request.
