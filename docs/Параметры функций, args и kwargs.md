# Параметры функций: позиционные аргументы, `*args` и `**kwargs`

## Параметры и аргументы

В определении функции записывают **параметры** — имена, под которыми значения будут доступны внутри функции. При вызове передают **аргументы** — конкретные значения для этих параметров. Аргумент можно передать по позиции или указать имя параметра явно.

```python
def describe_measurement(value: float, unit: str = "В") -> str:
    """Составить подпись для измерения.

    Args:
        value: Числовое значение.
        unit: Единица измерения.

    Returns:
        Подпись со значением и единицей измерения.
    """
    return f"{value} {unit}"


print(describe_measurement(5.2))                 # 5.2 В.
print(describe_measurement(5.2, "мВ"))           # 5.2 мВ.
print(describe_measurement(value=5.2, unit="мВ"))  # 5.2 мВ.
print(describe_measurement(unit="мВ", value=5.2))  # 5.2 мВ.
```

В первых двух вызовах значения сопоставляются параметрам по порядку. В двух последних используются **именованные аргументы**: перед знаком `=` записано имя параметра. Такой вызов часто легче читать, особенно когда у функции несколько необязательных настроек. `unit="В"` в определении задаёт значение по умолчанию, поэтому единицу можно не передавать.

Одному параметру нельзя передать значение дважды. Например, вызов `describe_measurement(5.2, value=7.0)` вызовет `TypeError`: параметр `value` уже получил значение по позиции. Именованный аргумент должен соответствовать параметру функции, если функция не принимает произвольные именованные аргументы через `**kwargs`.

## Параметры, передаваемые только по имени

Иногда функция должна требовать явного имени для части аргументов. Одиночная звёздочка в определении отделяет такие параметры:

```python
def convert_to_millivolts(value: float, *, scale: float = 1000.0) -> float:
    """Перевести показание в милливольты с заданным коэффициентом.

    Args:
        value: Исходное значение.
        scale: Коэффициент пересчёта.

    Returns:
        Результат пересчёта.
    """
    return value * scale


print(convert_to_millivolts(1.5))               # 1500.0.
print(convert_to_millivolts(1.5, scale=100.0))  # 150.0.
```

`value` можно передать по позиции, а `scale` — только по имени. Это называют параметром, **передаваемым только по имени**. Одиночная `*` в этой записи не создаёт кортеж и не означает `*args`.

## `*args`: произвольное количество позиционных аргументов

Если заранее неизвестно количество значений, в определении используют параметр со звёздочкой. По соглашению его называют `args`, хотя специальный смысл имеет именно `*`, а не слово `args`.

```python
def show_values(*args: int) -> None:
    """Вывести полученные целые числа.

    Args:
        *args: Значения для вывода.
    """
    print(args)  # Кортеж всех переданных позиционных значений.


numbers = [3, 1, 2]
show_values(3, 1, 2)  # (3, 1, 2).
show_values(*numbers)  # (3, 1, 2).
```

В определении `*args` **собирает** дополнительные позиционные аргументы в кортеж. При вызове `*numbers` выполняет обратное действие: **распаковывает** элементы списка в отдельные аргументы. Таким же образом можно распаковать кортеж.

## `**kwargs`: произвольные именованные аргументы

Две звёздочки в определении собирают дополнительные именованные аргументы в словарь. Имя `kwargs` тоже является соглашением, а не ключевым словом Python.

```python
def show_options(**kwargs: str) -> None:
    """Вывести переданные настройки.

    Args:
        **kwargs: Именованные настройки.
    """
    print(kwargs)  # Словарь с именами аргументов и их значениями.


show_options(unit="В", source="датчик")  # {'unit': 'В', 'source': 'датчик'}.

options = {"unit": "мВ", "source": "измеритель"}
show_options(**options)  # {'unit': 'мВ', 'source': 'измеритель'}.
```

В определении `**kwargs` **собирает** именованные аргументы в словарь. При вызове `**options` **распаковывает** пары ключ–значение из словаря в именованные аргументы. Ключи словаря должны быть строками. Если ключ передаётся явно объявленному параметру, он должен совпадать с именем этого параметра.

| Запись | В определении функции | При вызове функции |
| --- | --- | --- |
| `*args` | Собрать дополнительные позиционные аргументы в кортеж. | `*values` распаковывает последовательность в позиционные аргументы. |
| `**kwargs` | Собрать дополнительные именованные аргументы в словарь. | `**options` распаковывает словарь в именованные аргументы. |

Если набор допустимых настроек известен заранее, обычно лучше перечислить параметры явно: так легче увидеть допустимые имена и заметить опечатку. `**kwargs` полезен, когда функция действительно должна принимать или передавать дальше разные именованные настройки.

## Функция как аргумент: `*args` вместе с `**kwargs`

Имя функции без круглых скобок обозначает саму функцию. Её можно сохранить в переменной и передать другой функции. Запись `repeat_text(...)` уже вызывает функцию, а запись `function = repeat_text` сохраняет ссылку на неё.

Следующая функция получает вызываемую функцию вместе с её позиционными и именованными аргументами. Она передаёт их дальше и измеряет время между началом и окончанием вызова:

```python
from collections.abc import Callable
import time


def measure_execution_time(
    function: Callable[..., object],
    *args: object,
    **kwargs: object,
) -> tuple[object, float]:
    """Вызвать функцию и измерить время её выполнения.

    Args:
        function: Вызываемая функция.
        *args: Её позиционные аргументы.
        **kwargs: Её именованные аргументы.

    Returns:
        Результат функции и прошедшее время в секундах.
    """
    start_time = time.time()
    result = function(*args, **kwargs)
    stop_time = time.time()

    return result, stop_time - start_time


def repeat_text(text: str, count: int = 2, separator: str = " ") -> str:
    """Повторить текст заданное число раз.

    Args:
        text: Повторяемая строка.
        count: Количество повторов.
        separator: Разделитель между повторами.

    Returns:
        Строка из повторов текста.
    """
    return separator.join([text] * count)


function = repeat_text
result, elapsed = measure_execution_time(function, "Python", count=3, separator="-")
print(result)  # Python-Python-Python.
print(elapsed)  # Количество секунд зависит от запуска.
```

Здесь строка `"Python"` попадает в `args`, а пары `count=3` и `separator="-"` — в `kwargs`. При вызове `function(*args, **kwargs)` они снова передаются в `repeat_text`. Функция замера не обязана заранее знать имена всех параметров переданной ей функции.

## Самостоятельное задание. Отчёт по измерениям

Напишите функцию `make_report(title, *values, unit="В", **metadata)`, которая возвращает строку отчёта. `title` — заголовок, `values` — любое количество числовых измерений, `unit` — единица измерения, а `metadata` — дополнительные текстовые сведения, например `source="датчик"` и `room="лаборатория"`.

1. Включите в отчёт заголовок, количество значений и среднее значение. Если значений нет, вместо среднего укажите `нет данных`.
2. Выведите единицу измерения и все пары из `metadata` в том порядке, в котором они переданы.
3. Покажите два вызова: с явно записанными именованными аргументами и с распаковкой заранее подготовленных списка и словаря через `*` и `**`.
4. Передайте свою функцию в `measure_execution_time()` и выведите полученный отчёт и прошедшее время.
