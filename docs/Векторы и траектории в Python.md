## Атрибуты класса и экземпляра

**Атрибут класса** хранится у класса. Например, `Sensor.sample_rate` задаёт частоту измерений по умолчанию для датчиков. **Атрибут экземпляра** хранится у конкретного объекта. Присваивание `self.name = name` в `__init__()` задаёт имя каждого датчика.

```python
class Sensor:
    """Датчик с именем и частотой измерений."""

    sample_rate = 10

    def __init__(self, name: str) -> None:
        """Сохранить имя датчика."""
        self.name: str = name


first = Sensor("A")
second = Sensor("B")

print(first.name, second.name)  # A B
print(first.sample_rate, second.sample_rate)  # 10 10

first.sample_rate = 20
print(first.sample_rate, second.sample_rate)  # 20 10
print(Sensor.sample_rate)  # 10

Sensor.sample_rate = 30
print(first.sample_rate, second.sample_rate)  # 20 30
```

При чтении обычного атрибута `first.sample_rate` Python сначала ищет его у экземпляра, а затем у класса. Поэтому сначала оба датчика получают `10` из `Sensor`. Присваивание `first.sample_rate = 20` создаёт одноимённый атрибут у `first`, и при следующем чтении Python находит его первым.

Присваивание `Sensor.sample_rate = 30` меняет значение в классе. `second` читает новое значение из класса, а `first` продолжает читать своё `20`.

## Методы и свойства

При вызове обычного метода `obj.method(arg)` Python передаёт экземпляр `obj` первым аргументом. По соглашению этот параметр называют `self`. Декораторы меняют способ вызова метода или доступа к его результату.

### `@classmethod`

Метод класса получает сам класс первым аргументом. Этот параметр принято называть `cls`. Один из вариантов применения — альтернативный конструктор. Метод подготавливает аргументы и создаёт экземпляр вызовом `cls(...)`.

### `@staticmethod`

Статический метод получает только явно переданные аргументы. Такой метод удобно размещать в классе, когда его задача связана с классом, а для работы достаточно входных данных. Например, он может проверить или преобразовать переданное значение.

### `@property`

При чтении `obj.value` Python вызывает метод-геттер и возвращает его результат. Так можно открыть доступ к хранимому или вычисляемому значению с обычным синтаксисом атрибута. Свойство с одним геттером доступно для чтения.

## Специальные методы Python

Специальные методы, или *dunder methods*, имеют по два подчёркивания с каждой стороны имени. Python вызывает их при создании и вызове объектов, работе с операторами, встроенными функциями и квадратными скобками.

| Синтаксис | Метод | За что отвечает |
| --- | --- | --- |
| `SomeClass(...)` | `__init__` | Инициализирует только что созданный экземпляр. |
| `repr(obj)` | `__repr__` | Возвращает строковое представление объекта, например для отладки. |
| `str(obj)`, `print(obj)` | `__str__` | Возвращает строку для вывода пользователю. |
| `left + right` | `__add__` | Описывает сложение со стороны левого операнда. |
| `left * right` | `__mul__`, `__rmul__` | Позволяет левому или правому операнду обработать умножение. |
| `abs(obj)` | `__abs__` | Определяет абсолютное значение или модуль объекта. |
| `left @ right` | `__matmul__` | Задаёт поведение оператора `@`. Для матриц он используется для матричного умножения. |
| `obj[key]` | `__getitem__` | Возвращает значение по индексу или ключу. |
| `obj[key] = value` | `__setitem__` | Записывает значение по индексу или ключу. |
| `obj(...)` | `__call__` | Позволяет вызвать экземпляр как функцию. |

Специальный метод бинарной операции может вернуть `NotImplemented` для неподдерживаемого операнда. Тогда Python может попробовать реализацию другого операнда. Если операцию выполнить не удаётся, Python возбуждает `TypeError`.

### `repr()` и `str()`

`repr(obj)` вызывает `__repr__()`. Такое представление помогает при отладке, когда важно увидеть тип или состояние объекта. `str(obj)` вызывает `__str__()` и возвращает строку для чтения человеком. При выводе объекта `print(obj)` использует это же строковое представление.

Например, `print(repr("Python"))` выводит `'Python'` с кавычками, а `print(str("Python"))` выводит `Python`. Стандартный метод `object.__str__()` использует результат `__repr__()`, поэтому класс может обойтись одним представлением для обоих вызовов.

## Реализация `Vector2D`

В классе задаём размерность `DIMENSION = 2`, а в экземпляре храним компоненты `self._x` и `self._y`. Свойства `x` и `y` дают доступ к компонентам для чтения.

Конструктор `Vector2D(3, 4)` принимает готовые компоненты. Метод класса `Vector2D.from_points((1, 2), (4, 6))` вычисляет те же компоненты как разности координат конечной и начальной точек и передаёт их в `cls(3, 4)`. При одинаковом сдвиге обеих точек разности сохраняются.

Статический метод `_normalize_index(index, size)` применяет одинаковые правила в `__getitem__()` и `__setitem__()`. Индексы `0` и `-2` обращаются к первой компоненте, а `1` и `-1` — ко второй. Целый индекс за границами даёт `IndexError`, а индекс неподходящего типа, например строка `"x"`, — `TypeError`.

Для `v = Vector2D(3, 4)` и `w = Vector2D(1, 2)` получаем следующие результаты.

| Выражение | Результат |
| --- | --- |
| `repr(v)` | Строка `'Vector2D(3, 4)'`. |
| `v + w` | Новый вектор `Vector2D(4, 6)`. |
| `v * 2` и `2 * v` | Новый вектор `Vector2D(6, 8)` в обоих случаях. |
| `abs(v)` | $\sqrt{3^2+4^2}=5$. |
| `v.dot(w)` и `v @ w` | $3\cdot 1+4\cdot 2=11$. |
| `v[-1]` | `4` до присваивания `v[-1] = 7`, `7` после него. |

В `Vector2D` определён `__repr__()`, а `__str__()` унаследован от `object`. Поэтому `print(v)` и `print(repr(v))` выводят одну строку `Vector2D(3, 4)` для вектора с компонентами `3` и `4`.

В выражении `2 * v` класс `int` возвращает `NotImplemented`, после чего Python вызывает `v.__rmul__(2)`. Этот метод использует расчёт из `__mul__()`. По той же схеме `__matmul__()` вызывает `dot()`, чтобы формула скалярного произведения была записана в одном месте.

## Абстрактный класс траектории

Траектория задаёт положение на плоскости для каждого значения параметра $t$. Параметр может обозначать время при равномерном движении или задавать точку при обходе кривой. Объект траектории хранит коэффициенты, полученные при создании, а вызов `trajectory(t)` возвращает точку в виде `Vector2D`.

`Trajectory` наследуется от `ABC` и объявляет `__call__(t: float) -> Vector2D` с декоратором `@abstractmethod`. Конкретную формулу задаёт подкласс. При попытке создать экземпляр класса, у которого этот метод остаётся абстрактным, Python выдаёт `TypeError`.

| Траектория | Параметры объекта | Параметризация |
| --- | --- | --- |
| `LinearTrajectory` | Начальная точка `start`, направление `direction` | `start + t * direction` |
| `EllipticTrajectory` | Полуоси $a, b > 0$ | $x = a\cos t$, $y = b\sin t$ |
| `ParabolicTrajectory` | Коэффициенты $a, b, c$, где $a \ne 0$ | $x = t$, $y = at^2 + bt + c$ |
| `HyperbolicTrajectory` | Параметры $a, b > 0$, знак ветви $s \in \{-1, 1\}$ | $x = sa\cosh t$, $y = b\sinh t$ |

Подстановка параметризации эллипса в $(x/a)^2+(y/b)^2=1$ сводит его уравнение к $\cos^2 t+\sin^2 t=1$. Для гиперболы $(x/a)^2-(y/b)^2=1$ аналогичную роль играет $\cosh^2 t-\sinh^2 t=1$.

## Один способ построить разные кривые

Для запуска примеров нужны Python 3.10 или новее и библиотеки из занятия [NumPy и Matplotlib](NumPy%20и%20Matplotlib.md).

Для прямолинейного движения возьмём две позиции. Объект за две секунды прошёл из `(1, 2)` в `(4, 6)`. Делим компоненты перемещения `(3, 4)` на время и получаем скорость `(1.5, 2.0)`. Подставляем её в выражение `start + t * velocity` и получаем положение `(5.5, 8.0)` через три секунды от начала движения.

`plot_trajectory()` получает траекторию и одномерный массив NumPy со значениями `t`. Функция вычисляет точки через `trajectory(t)`, читает их координаты и передаёт их в `ax.plot()`. Для прямой можно взять интервал от `0` до `3`, для полного обхода эллипса — от $0$ до $2\pi$. Подкласс выбирает формулу точки, а функция построения работает одинаково.

## Самостоятельная работа

1. **Проверьте индексацию.** Для `Vector2D(3, 4)` сравните значения `v[0]` и `v[-2]`. Присвойте `v[-1] = 7` и прочитайте `v.y`. Проверьте чтение и запись для индекса `2`, а также для индекса `"x"`. Объясните, почему возникают разные типы исключений.
2. **Добавьте `ParabolicTrajectory(a, b, c)`.** При $a=0$ конструктор должен возбуждать `ValueError`. Для `ParabolicTrajectory(1, -2, 3)` при `t = 2` ожидается точка `(2, 3)`. Постройте кривую для $-2 \le t \le 3$.
3. **Добавьте `HyperbolicTrajectory(a, b, branch=1)`.** Используйте `math.cosh()` и `math.sinh()`. При `t = 0` и `a = 3` правая ветвь даёт точку `(3, 0)`, а левая — `(-3, 0)`. Для обеих ветвей попробуйте диапазон $-1.5 \le t \le 1.5$.
4. **Постройте все кривые через `plot_trajectory()`.** Передайте ей новые экземпляры и соответствующие массивы значений `t`. Объясните, какие методы вызываются у траектории и у полученных векторов.

На следующем занятии вынесем создание траектории в `create_trajectory()`. Базовый построитель будет задавать общий порядок работы, а его подклассы будут выбирать, какой класс траектории создать. На этом примере разберём паттерн «Фабричный метод».
