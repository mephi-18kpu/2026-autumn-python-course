# Численное интегрирование

## Описание

Программа вычисляет интеграл функции `exp(x)` на отрезке от 0 до 1 пятью численными методами:

- левые прямоугольники;
- правые прямоугольники;
- средние прямоугольники;
- трапеции;
- метод Симпсона.

Программа выводит таблицу абсолютных погрешностей и строит общий график зависимости погрешности от шага сетки в логарифмических координатах.

## Математическая задача

Вычисляется интеграл:

```text
интеграл от 0 до 1 функции e в степени x
```

Точное значение:

```text
e - 1 = 1.718281828459045...
```

## Ожидаемые порядки погрешности

- Левые и правые прямоугольники: O(h).
- Средние прямоугольники и трапеции: O(h^2).
- Метод Симпсона: O(h^4).

При уменьшении шага в два раза погрешность в теоретическом режиме уменьшается примерно в 2, 4 и 16 раз соответственно.
