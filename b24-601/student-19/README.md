# Рабочая директория `student-19`

Директория предназначена для постоянной работы студента группы `b24-601` с идентификатором `student-19`.

## Параметры

- Группа: `b24-601`.
- Идентификатор студента: `student-19`.
- Рабочая ветка: `student/b24-601/student-19`.

## Правила работы

Размещайте учебные файлы только в этой директории, если преподаватель не указал иной порядок. Не изменяйте директории и ветки других студентов.
