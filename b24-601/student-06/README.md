# Рабочая директория `student-06`

Директория предназначена для постоянной работы студента группы `b24-601` с идентификатором `student-06`.

## Параметры

- Группа: `b24-601`.
- Идентификатор студента: `student-06`.
- Рабочая ветка: `student/b24-601/student-06`.

## Правила работы

Размещайте учебные файлы только в этой директории, если преподаватель не указал иной порядок. Не изменяйте директории и ветки других студентов.
