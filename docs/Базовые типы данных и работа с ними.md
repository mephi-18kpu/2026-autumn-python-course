# Базовые типы данных и работа с ними

На предыдущем занятии вы уже использовали переменные, `input()`, `int()`, сравнения, `if-elif-else` и f-строки. Теперь рассмотрим модель данных Python подробнее и научимся обрабатывать наборы значений.

## Переменные, объекты и типы

В Python переменная — это имя, связанное с объектом:

```python
student_name = "Анна"
score = 75
temperature = 23.5
is_admitted = True
```

Каждый объект имеет тип. Его можно узнать с помощью функции `type()`:

```python
print(type(student_name))  # <class 'str'>
print(type(score))         # <class 'int'>
print(type(temperature))   # <class 'float'>
print(type(is_admitted))   # <class 'bool'>
```

Тип принадлежит объекту, а не имени переменной. Одно имя технически можно связать сначала с числом, а затем со строкой:

```python
value = 10
value = "десять"
```

Python допускает такое переприсваивание, но без необходимости менять смысл и тип значения переменной не следует: это усложняет чтение программы.

## Основные встроенные типы

| Тип | Назначение | Примеры |
|---|---|---|
| `int` | целые числа | `0`, `15`, `-8` |
| `float` | вещественные числа | `3.14`, `-0.5`, `2.0` |
| `bool` | логические значения | `True`, `False` |
| `str` | строки | `"датчик"`, `"A-17"` |
| `NoneType` | отсутствие значения | `None` |

### Целые числа `int`

Тип `int` хранит целые числа без дробной части. Целые числа могут быть положительными, отрицательными или равными нулю:

```python
student_count = 25
temperature_offset = -5
error_count = 0
```

Размер значения `int` в Python не ограничен фиксированными 32 или 64 битами: число может увеличиваться, пока для него хватает памяти. Тип `int` подходит для счётчиков, индексов, кодов и дискретных величин.

```python
completed_tasks = 7
total_tasks = 10
remaining_tasks = total_tasks - completed_tasks

print(f"Осталось заданий: {remaining_tasks}")
```

### Вещественные числа `float`

Тип `float` хранит числа с дробной частью. Его используют для результатов измерений, коэффициентов и приближённых вычислений:

```python
voltage = 12.5
current = 1.2
power = voltage * current

print(f"Мощность: {power} Вт")
```

Большинство значений `float` хранится приближённо, потому что многие десятичные дроби нельзя точно представить конечной двоичной дробью. Поэтому даже результат простого вычисления может не совпасть с ожидаемой десятичной записью:

```python
result = 0.1 + 0.2

print(result)         # 0.30000000000000004
print(result == 0.3)  # False
```

Если не учитывать эту особенность, программа может:

- ошибочно перейти в другую ветвь условия;
- не найти рассчитанное значение в коллекции;
- неправильно определить достижение граничного значения;
- не завершить цикл, который ожидает точного совпадения;
- накопить заметную погрешность после большого количества операций.

Результаты вычислений с `float` не следует проверять на точное равенство через `==` или `!=`. Обычно сравнивают модуль разности с допустимой погрешностью:

```python
result = 0.1 + 0.2
expected_result = 0.3
tolerance = 1e-9

are_equal = abs(result - expected_result) < tolerance
print(are_equal)  # True
```

Сравнения порядка `<`, `>`, `<=` и `>=` применять можно, например при проверке диапазона измерений. Однако вблизи границы также необходимо решить, какая погрешность допустима для конкретной задачи.

Для денежных и других величин, где требуется точная десятичная арифметика, обычный `float` может быть неподходящим. В таких задачах используют целое количество минимальных единиц или специальные средства десятичной арифметики.

### Логические значения `bool`

Тип `bool` содержит только два значения: `True` и `False`. Обычно логическое значение является результатом сравнения или проверки состояния:

```python
temperature = 25.0
is_temperature_normal = 20.0 <= temperature <= 30.0
is_sensor_connected = True

print(is_temperature_normal)  # True
print(is_sensor_connected)    # True
```

Имена логических переменных удобно формулировать как утверждения: `is_valid`, `has_errors`, `can_start`. Тогда условие читается как обычная фраза:

```python
if is_sensor_connected and is_temperature_normal:
    print("Система готова к работе")
```

### Строки `str`

Тип `str` хранит текст как последовательность символов Unicode. Строки могут содержать кириллицу, латиницу, цифры, пробелы и специальные символы:

```python
device_name = "Датчик температуры"
device_code = "TMP-01"
status_message = "Устройство готово\nМожно начинать измерения"
```

Строковые значения записывают в одинарных или двойных кавычках. Внутри одного проекта следует придерживаться единообразного оформления.

### Отсутствующее значения `None`

Значение `None` используют, когда содержательного результата нет, значение ещё не определено или функция ничего не должна возвращать:

```python
measurement = None
```

`None` не является нулём, пустой строкой или значением `False`. Это отдельный объект, обозначающий отсутствие значения.

```python
last_measurement = None

if last_measurement is None:
    print("Измерения ещё не получены")
```

Для проверки `None` используют `is None` или `is not None`, а не операторы `==` и `!=`.

## Арифметические операции

| Оператор | Операция | Пример | Результат |
|---|---|---|---|
| `+` | сложение | `7 + 3` | `10` |
| `-` | вычитание | `7 - 3` | `4` |
| `*` | умножение | `7 * 3` | `21` |
| `/` | обычное деление | `7 / 3` | `2.333...` |
| `//` | целочисленное деление | `7 // 3` | `2` |
| `%` | остаток от деления | `7 % 3` | `1` |
| `**` | возведение в степень | `2 ** 3` | `8` |

Обычное деление `/` возвращает значение типа `float`, даже если результат является целым числом:

```python
print(8 / 2)   # 4.0
print(8 // 2)  # 4
```

## Сравнения и логические операции

Результат сравнения имеет тип `bool`:

```python
temperature = 25.0

print(temperature > 20.0)   # True
print(temperature == 25.0)  # True
print(temperature != 25.0)  # False
```

Основные операторы сравнения: `>`, `<`, `>=`, `<=`, `==`, `!=`.

Оператор `==` сравнивает значения объектов, а оператор `is` проверяет, являются ли две переменные именами одного и того же объекта:

```python
first_values = [10, 20]
second_values = [10, 20]
same_values = first_values

print(first_values == second_values)  # True
print(first_values is second_values)  # False
print(first_values is same_values)    # True
```

Списки `first_values` и `second_values` содержат одинаковые элементы, поэтому сравнение через `==` возвращает `True`. При этом это два разных объекта, поэтому проверка через `is` возвращает `False`. Переменные `first_values` и `same_values` связаны с одним списком.

Для сравнения чисел, строк и содержимого коллекций используют `==` и `!=`. Операторы `is` и `is not` применяют, когда важна идентичность объекта. Наиболее распространённый случай — проверка значения `None`:

```python
measurement = None

if measurement is None:
    print("Измерение отсутствует")
```

Не следует использовать `is` для сравнения чисел и строк. Интерпретатор может повторно использовать некоторые неизменяемые объекты, поэтому результат такой проверки способен зависеть от деталей реализации Python, а не от равенства значений.

В Python можно записывать цепочки сравнений:

```python
temperature = 25.0
is_normal = 20.0 <= temperature <= 30.0
```

Логические операции позволяют объединять или изменять условия:

- `and` истинно, если истинны оба условия;
- `or` истинно, если истинно хотя бы одно условие;
- `not` меняет логическое значение на противоположное.

```python
temperature = 25.0
pressure = 101.3

is_normal = temperature < 30.0 and pressure < 110.0
is_alarm = temperature > 50.0 or pressure > 150.0
is_safe = not is_alarm
```

## Преобразование типов

Некоторые значения можно явно преобразовывать из одного типа в другой:

```python
count = int("15")
voltage = float("12.5")
message = str(42)
```

Невозможное преобразование приводит к ошибке:

```python
count = int("пятнадцать")  # ValueError
```

Функция `bool()` преобразует объект в логическое значение. Нулевые числа, пустые строки и пустые коллекции считаются ложными:

```python
print(bool(0))     # False
print(bool(""))    # False
print(bool([]))    # False
print(bool(10))    # True
print(bool("0"))   # True
```

Строка `"0"` истинна, потому что она не пустая.

## Последовательности

Последовательность хранит элементы в определённом порядке. К последовательностям относятся строки, списки и кортежи.

Общие операции над последовательностями:
- получение элемента по индексу;
- получение части последовательности с помощью среза;
- определение длины через `len()`;
- проверка наличия элемента через `in`;
- перебор элементов в цикле.

### Индексы

Индексация начинается с нуля:

```python
sensor_names = ["давление", "температура", "скорость"]

print(sensor_names[0])   # давление
print(sensor_names[1])   # температура
print(sensor_names[-1])  # скорость
```

Отрицательные индексы отсчитывают элементы с конца последовательности.

Обращение к несуществующему индексу приводит к `IndexError`:

```python
print(sensor_names[10])  # IndexError
```

### Срезы

Срез позволяет получить новую последовательность, содержащую выбранную часть исходной. Полная форма среза содержит три параметра:

```text
sequence[start:stop:step]
```

- `start` — индекс первого включаемого элемента;
- `stop` — индекс границы, которая не включается в результат;
- `step` — шаг между выбираемыми элементами.

Все три параметра можно указывать одновременно:

```python
measurements = [10, 20, 30, 40, 50, 60, 70]

print(measurements[1:6:2])  # [20, 40, 60]
```

Срез начинается с элемента с индексом `1`, останавливается перед индексом `6` и выбирает каждый второй элемент.

Если шаг равен `1`, его обычно не записывают:

```python
measurements = [10, 20, 30, 40, 50]

print(measurements[1:4])  # [20, 30, 40]
print(measurements[:3])   # [10, 20, 30]
print(measurements[3:])   # [40, 50]
```

Правая граница среза не включается в результат.

Если `start` не указан, срез начинается от начала последовательности. Если не указан `stop`, срез продолжается до конца:

```python
measurements = [10, 20, 30, 40, 50, 60]

print(measurements[:5:2])  # [10, 30, 50]
print(measurements[1::2])  # [20, 40, 60]
```

Шаг может быть отрицательным. Тогда элементы выбираются справа налево:

```python
measurements = [10, 20, 30, 40, 50, 60]

print(measurements[5:1:-2])  # [60, 40]
print(measurements[::-1])    # [60, 50, 40, 30, 20, 10]
```

При отрицательном шаге начальный индекс должен находиться правее конечной границы. Запись `[::-1]` часто используют для получения последовательности в обратном порядке.

Отрицательные индексы можно применять и в границах среза:

```python
measurements = [10, 20, 30, 40, 50, 60]

print(measurements[-5:-1:2])  # [20, 40]
```

Срез `[:]` выбирает все элементы. Для списка при этом создаётся новый список:

```python
measurements = [10, 20, 30]
measurements_copy = measurements[:]
```

Выход границы среза за пределы последовательности не приводит к `IndexError`: Python использует существующую часть последовательности.

```python
measurements = [10, 20, 30]

print(measurements[0:100:1])  # [10, 20, 30]
```

Шаг среза не может быть равен нулю: запись `measurements[0:3:0]` приводит к `ValueError`.

## Строки

Строка `str` — неизменяемая последовательность символов:

```python
device_name = "sensor"

print(device_name[0])    # s
print(device_name[1:4])  # ens
print(len(device_name))  # 6
print("sen" in device_name)  # True
```

Строки можно объединять оператором `+` и повторять оператором `*`:

```python
device_type = "sensor"
device_number = "-01"

device_code = device_type + device_number
separator = "-" * 20

print(device_code)  # sensor-01
print(separator)    # --------------------
```

Методы строк возвращают новые строки, не изменяя исходную:

```python
raw_device_name = "  Temperature Sensor  "
device_name = raw_device_name.strip().lower()

print(device_name)      # temperature sensor
print(raw_device_name)  # исходная строка не изменилась
```

### Функции и методы для работы со строками

Встроенные функции вызываются отдельно и получают строку как аргумент. Некоторые полезные функции:

- `len()` возвращает количество символов;
- `str()` преобразует объект в строку;
- `ord()` возвращает числовой код символа Unicode;
- `chr()` создаёт символ по его коду Unicode.

```python
device_name = "Датчик"
measurement = 25.4

print(len(device_name))       # 6
print(str(measurement))       # 25.4
print(ord("A"))               # 65
print(chr(65))                # A
```

Метод принадлежит строковому объекту и вызывается через точку. Поскольку строки неизменяемы, строковые методы не изменяют исходную строку, а возвращают новый результат.

Изменение регистра:

```python
device_name = "Temperature Sensor"

print(device_name.lower())       # temperature sensor
print(device_name.upper())       # TEMPERATURE SENSOR
print(device_name.capitalize())  # Temperature sensor
```

Удаление пробельных символов по краям:

```python
raw_value = "  25.4\n"

print(raw_value.strip())   # 25.4
print(raw_value.lstrip())  # удалены пробелы слева
print(raw_value.rstrip())  # удалены пробелы и перевод строки справа
```

Поиск, подсчёт и проверка частей строки:

```python
message = "sensor-01: temperature sensor"

print(message.find("sensor"))           # 0
print(message.count("sensor"))          # 2
print(message.startswith("sensor-01"))  # True
print(message.endswith("sensor"))       # True
```

Метод `find()` возвращает индекс первого совпадения или `-1`, если фрагмент не найден. Для обычной проверки наличия подстроки проще использовать оператор `in`:

```python
message = "sensor-01: ready"

if "ready" in message:
    print("Датчик готов")
```

Замена фрагмента:

```python
message = "sensor-01: offline"
updated_message = message.replace("offline", "online")

print(updated_message)  # sensor-01: online
print(message)          # исходная строка не изменилась
```

Разделение строки и объединение последовательности строк:

```python
sensor_data = "temperature,pressure,speed"
sensor_names = sensor_data.split(",")
formatted_names = ", ".join(sensor_names)

print(sensor_names)      # ['temperature', 'pressure', 'speed']
print(formatted_names)   # temperature, pressure, speed
```

Метод `split()` возвращает список частей строки. Метод `join()` вызывают у строки-разделителя и передают ему последовательность строк.

Изменить отдельный символ строки нельзя:

```python
device_name[0] = "S"  # TypeError
```

Вместо изменения создаётся новая строка:

```python
device_name = "S" + device_name[1:]
```

## Списки

Список `list` — изменяемая упорядоченная коллекция. Он подходит для набора значений, в котором важен порядок и состав которого может меняться:

```python
measurements = [12.5, 13.1, 12.8]
```

Список может содержать объекты разных типов, но однородные списки обычно проще обрабатывать и понимать:

```python
temperatures = [21.5, 22.0, 23.1]
device_names = ["датчик 1", "датчик 2", "датчик 3"]
```

Элементы списка можно читать и изменять:

```python
measurements[0] = 12.7
print(measurements)  # [12.7, 13.1, 12.8]
```

Основные операции:

```python
measurements.append(13.4)  # добавить элемент в конец
measurements.insert(1, 12.9)  # вставить элемент по индексу
measurements.remove(13.1)  # удалить первое указанное значение
last_measurement = measurements.pop()  # удалить и вернуть последний элемент
```

Функции `len()`, `min()`, `max()` и `sum()` часто применяют к спискам чисел:

```python
measurements = [12.5, 13.1, 12.8]

print(len(measurements))
print(min(measurements))
print(max(measurements))
print(sum(measurements))
```

При обращении к элементам во время удаления нужно учитывать, что индексы остальных элементов изменяются.

## Кортежи

Кортеж `tuple` — неизменяемая упорядоченная коллекция. Как и список, он поддерживает индексы, срезы, `len()` и проверку вхождения, но после создания нельзя заменить, добавить или удалить его элементы:

```python
point = (10.0, 25.0)

print(point[0])
print(point[1])
print(len(point))
```

Изменить элемент кортежа нельзя:

```python
point[0] = 15.0  # TypeError
```

Кортеж подходит для набора значений, состав которого не должен меняться, например для координат точки или границ диапазона.

Кортеж из одного элемента обязательно содержит запятую:

```python
single_value = (10,)
```

Без запятой выражение `(10)` является обычным числом в скобках.

## Словари

Словарь `dict` — изменяемая коллекция пар «ключ — значение». Вместо числового индекса значение получают по связанному с ним ключу. Словари подходят для описания объектов с именованными характеристиками, поиска данных по идентификатору и подсчёта повторений:

```python
equipment = {
    "мультиметр": 8,
    "осциллограф": 3,
    "генератор": 2,
}
```

Значение получают по ключу:

```python
print(equipment["мультиметр"])  # 8
```

Словарь является изменяемым. Можно изменить существующее значение или добавить новую пару:

```python
equipment["мультиметр"] = 7
equipment["источник питания"] = 4
```

Удалить пару можно оператором `del` или методом `pop()`:

```python
del equipment["генератор"]
removed_count = equipment.pop("осциллограф")
```

Перед обращением к ключу его наличие можно проверить:

```python
device_name = "осциллограф"

if device_name in equipment:
    print(equipment[device_name])
```

Обращение к отсутствующему ключу через квадратные скобки приводит к `KeyError`.

Метод `get()` позволяет получить значение без `KeyError`. Если ключ отсутствует, метод возвращает `None`:

```python
oscilloscope_count = equipment.get("осциллограф")

if oscilloscope_count is None:
    print("Осциллографы не зарегистрированы")
```

Для получения содержимого словаря предусмотрены три основных метода:

- `keys()` возвращает все ключи;
- `values()` возвращает все значения;
- `items()` возвращает пары из ключей и значений.

```python
equipment = {
    "мультиметр": 8,
    "осциллограф": 3,
    "генератор": 2,
}

print(equipment.keys())
print(equipment.values())
print(equipment.items())
```

Результаты этих методов можно перебирать в цикле:

```python
for device_name in equipment.keys():
    print(device_name)

for count in equipment.values():
    print(count)

for device_name, count in equipment.items():
    print(f"{device_name}: {count}")
```

Обычный цикл по словарю также перебирает его ключи:

```python
for device_name in equipment:
    print(device_name)
```

Ключом словаря может быть не только строка. Подходят хешируемые объекты, значение которых не изменяется во время использования в качестве ключа. Например, ключами могут быть числа, строки и кортежи из неизменяемых элементов:

```python
error_descriptions = {
    101: "Потеря связи",
    205: "Недопустимое значение",
}

measurements_by_position = {
    (0, 0): 21.5,
    (0, 1): 22.0,
    (1, 0): 21.8,
}
```

Python использует хеш ключа для быстрого поиска соответствующего значения. Поэтому изменяемые объекты `list`, `dict` и `set` ключами быть не могут: изменение такого объекта сделало бы ранее вычисленный хеш ненадёжным.

```python
invalid_dictionary = {
    [0, 0]: 21.5,  # TypeError: список нельзя использовать как ключ
}
```

Значениями словаря могут быть объекты любых типов, включая списки и другие словари.

## Множества

Множество `set` — изменяемая неиндексируемая коллекция уникальных элементов. Оно подходит для удаления повторений, быстрой проверки принадлежности и операций над группами объектов:

```python
sensor_names = {"температура", "давление", "скорость"}
```

Повторяющиеся элементы при создании множества удаляются:

```python
error_codes = [101, 205, 101, 404, 205]
unique_error_codes = set(error_codes)

print(unique_error_codes)
```

Порядок элементов множества не следует считать фиксированным. Получить элемент множества по индексу нельзя.

Основные операции:

```python
unique_error_codes.add(500)
unique_error_codes.remove(101)

print(205 in unique_error_codes)
```

Для двух множеств доступны объединение, пересечение и разность:

```python
first_codes = {101, 205, 404}
second_codes = {205, 404, 500}

print(first_codes | second_codes)  # объединение
print(first_codes & second_codes)  # пересечение
print(first_codes - second_codes)  # разность
```

Пустое множество создают с помощью `set()`:

```python
empty_set = set()
```

Запись `{}` создаёт пустой словарь, а не множество.

## Условия

Условия позволяют выполнить разные действия в зависимости от данных:

```python
temperature = 75.0

if temperature > 80.0:
    print("Аварийная температура")
elif temperature > 60.0:
    print("Повышенная температура")
else:
    print("Нормальная температура")
```

Условия проверяются сверху вниз. После выполнения одной ветви остальные ветви этой конструкции пропускаются.

## Цикл `for`

Цикл `for` последовательно получает элементы и выполняет для каждого из них один блок кода:

```python
measurements = [12.5, 13.1, 12.8]

for measurement in measurements:
    print(measurement)
```

Для перебора элементов списка обычно не требуется вручную работать с индексами.

### Накопление результата

```python
measurements = [12.5, 13.1, 12.8]
total = 0.0

for measurement in measurements:
    total = total + measurement

average = total / len(measurements)
print(f"Среднее значение: {average}")
```

Переменная `total` является накопителем: на каждой итерации к ней добавляется очередное значение.

### Подсчёт элементов

```python
measurements = [12.5, 31.0, 28.4, 35.2]
threshold = 30.0
exceedance_count = 0

for measurement in measurements:
    if measurement > threshold:
        exceedance_count = exceedance_count + 1

print(f"Количество превышений: {exceedance_count}")
```

### `range()`

Функция `range()` создаёт последовательность целых чисел:

```python
for number in range(5):
    print(number)
```

Будут выведены числа от `0` до `4`. Правая граница не включается.

```python
for number in range(2, 6):
    print(number)
```

Будут выведены числа от `2` до `5`.

### `enumerate()`

Если одновременно нужны индекс и значение, используют `enumerate()`:

```python
measurements = [12.5, 13.1, 12.8]

for index, measurement in enumerate(measurements):
    print(f"Измерение {index}: {measurement}")
```

## Цикл `while`

Цикл `while` повторяется, пока его условие истинно:

```python
attempt = 1

while attempt <= 3:
    print(f"Попытка: {attempt}")
    attempt = attempt + 1
```

Перед использованием `while` необходимо понимать, какое действие сделает условие ложным. Иначе цикл может стать бесконечным.

## `break` и `continue`

Оператор `break` немедленно завершает ближайший цикл:

```python
measurements = [12.5, 13.1, -1.0, 12.8]

for measurement in measurements:
    if measurement < 0.0:
        print("Обнаружено некорректное измерение")
        break
```

Оператор `continue` пропускает оставшуюся часть текущей итерации и переходит к следующей:

```python
measurements = [12.5, -1.0, 13.1, -2.0, 12.8]

for measurement in measurements:
    if measurement < 0.0:
        continue

    print(measurement)
```

## Функции

Функция объединяет действия, решающие отдельную задачу. Она объявляется с помощью `def`:

```python
def calculate_power(voltage: float, current: float) -> float:
    """Вычисляет электрическую мощность."""
    return voltage * current
```

`voltage` и `current` — параметры функции. При вызове им передаются конкретные аргументы:

```python
power = calculate_power(12.0, 1.5)
print(f"Мощность: {power} Вт")
```

В этом примере аргументы передаются позиционно:

- значение `12.0` поступает в первый параметр `voltage`;
- значение `1.5` поступает во второй параметр `current`;
- порядок аргументов влияет на результат вызова.

На этом занятии используются только обязательные параметры и позиционная передача аргументов.

### Параметры и возвращаемое значение

```python
def count_exceedances(
    measurements: list[float],
    threshold: float,
) -> int:
    """Подсчитывает измерения выше указанного порога."""
    exceedance_count = 0

    for measurement in measurements:
        if measurement > threshold:
            exceedance_count = exceedance_count + 1

    return exceedance_count


measurements = [12.5, 31.0, 28.4, 35.2]
count = count_exceedances(measurements, 30.0)
print(f"Количество превышений: {count}")
```

Оператор `return`:

- завершает выполнение функции;
- передаёт результат в место вызова;
- позволяет сохранить результат в переменной или использовать его в выражении.

Если функция завершилась без `return`, она возвращает `None`:

```python
def print_device_name(device_name: str) -> None:
    """Выводит название устройства."""
    print(device_name)
```

### Локальные переменные

Переменная, созданная внутри функции, является локальной и предназначена для работы этой функции:

```python
def calculate_average(measurements: list[float]) -> float:
    """Вычисляет среднее арифметическое измерений."""
    total = sum(measurements)
    return total / len(measurements)
```

Переменная `total` за пределами функции недоступна.

Аннотации `list[float]`, `float` и `int` описывают ожидаемые типы параметров и результата. Они помогают читать код, но сами по себе не выполняют автоматическую проверку типов во время работы программы.

## Изменяемые и неизменяемые объекты

Объекты Python можно разделить на две группы.

Неизменяемые объекты:

- `int`;
- `float`;
- `bool`;
- `str`;
- `tuple`;
- `None`.

Изменяемые объекты:

- `list`;
- `dict`;
- `set`.

Операция над неизменяемым объектом создаёт новый объект и связывает с ним имя:

```python
count = 10
count = count + 1
```

Значение целого числа `10` не изменилось. Выражение создало результат `11`, после чего имя `count` было связано с новым объектом.

Список можно изменить без переприсваивания имени:

```python
measurements = [10.0, 20.0]
measurements.append(30.0)
```

### Несколько имён одного объекта

Присваивание списка другой переменной не создаёт копию:

```python
first_values = [10, 20]
second_values = first_values

second_values.append(30)

print(first_values)   # [10, 20, 30]
print(second_values)  # [10, 20, 30]
```

Обе переменные связаны с одним списком. Изменение через одну переменную видно через другую.

Независимую поверхностную копию списка можно создать методом `copy()`:

```python
first_values = [10, 20]
second_values = first_values.copy()

second_values.append(30)

print(first_values)   # [10, 20]
print(second_values)  # [10, 20, 30]
```

### Изменяемый объект как аргумент функции

Функция может изменить переданный ей список:

```python
def add_measurement(
    measurements: list[float],
    new_measurement: float,
) -> None:
    """Добавляет новое измерение в список."""
    measurements.append(new_measurement)


values = [10.0, 20.0]
add_measurement(values, 30.0)

print(values)  # [10.0, 20.0, 30.0]
```

Такое изменение называется побочным эффектом. При проектировании функции важно заранее понимать, должна ли она менять переданный объект или возвращать новый результат.

## Пример программы: обработка измерений

Программа отбрасывает отрицательные измерения, вычисляет среднее допустимых значений и подсчитывает превышения порога.

```python
"""Обработка результатов измерений."""

# System imports

# External imports

# User imports

#############################################


def select_valid_measurements(
    measurements: list[float],
) -> list[float]:
    """Возвращает список неотрицательных измерений."""
    valid_measurements = []

    for measurement in measurements:
        if measurement < 0.0:
            continue

        valid_measurements.append(measurement)

    return valid_measurements


def calculate_average(measurements: list[float]) -> float:
    """Вычисляет среднее арифметическое измерений."""
    return sum(measurements) / len(measurements)


def count_exceedances(
    measurements: list[float],
    threshold: float,
) -> int:
    """Подсчитывает измерения выше указанного порога."""
    exceedance_count = 0

    for measurement in measurements:
        if measurement > threshold:
            exceedance_count = exceedance_count + 1

    return exceedance_count


MEASUREMENT_THRESHOLD = 30.0

measurements = [25.5, -1.0, 31.2, 28.4, 35.0]
valid_measurements = select_valid_measurements(measurements)

if len(valid_measurements) > 0:
    average = calculate_average(valid_measurements)
    exceedance_count = count_exceedances(
        valid_measurements,
        MEASUREMENT_THRESHOLD,
    )

    print(f"Допустимые измерения: {valid_measurements}")
    print(f"Среднее значение: {average}")
    print(f"Количество превышений: {exceedance_count}")
else:
    print("Допустимые измерения отсутствуют.")
```

Обратите внимание:

- исходный список не изменяется;
- каждая функция решает одну задачу;
- результаты вычислений возвращаются через `return`;
- аргументы передаются только позиционно;
- перед вычислением среднего проверяется, что список не пустой.

def select_high_measurements(

### Решение задания 3. Подсчёт кодов ошибок

```python
def count_error_codes(error_codes: list[int]) -> dict[int, int]:
    """Подсчитывает количество появлений каждого кода ошибки."""
    error_counts = {}

    for error_code in error_codes:
        if error_code in error_counts:
            error_counts[error_code] = error_counts[error_code] + 1
        else:
            error_counts[error_code] = 1

    return error_counts


error_codes = [101, 205, 101, 404, 205, 101]
error_counts = count_error_codes(error_codes)

print(error_counts)
```

При первом появлении кода в словаре создаётся элемент со значением `1`. При следующих появлениях значение по этому ключу увеличивается.

### Решение задания 5. Общий список

В исходной программе переменные `first_values` и `second_values` ссылаются на один изменяемый объект `list`. Поэтому добавление элемента через `second_values` изменяет список, доступный через обе переменные, и программа выводит `[1, 2, 3]`.

Чтобы получить два независимых списка, можно создать поверхностную копию с помощью метода `copy()`:

```python
first_values = [1, 2]
second_values = first_values.copy()

second_values.append(3)

print(first_values)
print(second_values)
```

Теперь программа выводит:

```text
[1, 2]
[1, 2, 3]
```
