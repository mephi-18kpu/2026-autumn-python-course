# Модули, `pathlib` и NumPy

## Выполнение `.py`-файлов и импорт

В `.py`-файле можно записывать команды последовательно, не создавая функцию `main()`. При запуске файла Python выполняет команды сверху вниз. Определение функции создаёт функцию, но не вызывает её; выражения и вызовы функций на верхнем уровне выполняются сразу. Имя `main` не обладает специальным значением для Python: так часто называют функцию, с которой начинают основную часть программы.

Файл с кодом можно использовать как модуль и импортировать из другого файла. При первом импорте Python также выполняет команды на верхнем уровне импортируемого модуля. Это позволяет определить в одном файле функции и вызвать их из другого, но важно помнить: команды вне функций при импорте тоже выполнятся.

### `__name__` и `__file__` на примере двух файлов

Сохраните рядом файлы [main.py](main.py) и [other_file.py](other_file.py). `other_file.py` содержит функции вычисления средней оценки и отбора оценок не ниже четырёх. `main.py` импортирует эти функции, запрашивает оценки и выводит результат. В `main.py` нет ни функции `main()`, ни условия с `__name__`: его основная программа записана последовательно.

**`other_file.py`:**

```python
"""Функции для обработки оценок и пример их самостоятельного запуска."""

# System imports

# External imports

# User imports

#############################################


def calculate_average(scores: list[int]) -> float:
    """Вычислить среднюю оценку.

    Args:
        scores: Непустой список оценок.

    Returns:
        Средняя оценка.
    """
    return sum(scores) / len(scores)


def get_good_scores(scores: list[int]) -> list[int]:
    """Выбрать оценки не ниже четырёх.

    Args:
        scores: Список оценок.

    Returns:
        Список оценок не ниже четырёх.
    """
    result = []

    for score in scores:
        if score >= 4:
            result.append(score)

    return result


print("Значение __name__ в other_file.py:", __name__)  # __main__ или other_file.
print("Значение __file__ в other_file.py:", __file__)  # Путь к other_file.py.

if __name__ == "__main__":
    example_scores = [5, 3, 4, 5]
    print("Проверка средней оценки:", calculate_average(example_scores))  # 4.25.
    print("Проверка отбора оценок:", get_good_scores(example_scores))  # [5, 4, 5].
```

**`main.py`:**

```python
"""Программа для анализа введённых оценок."""

# System imports

# External imports

# User imports
from other_file import calculate_average, get_good_scores

#############################################


print("Значение __name__ в main.py:", __name__)  # При прямом запуске: __main__.
print("Значение __file__ в main.py:", __file__)  # Путь к main.py.

entered_scores = input("Введите оценки через пробел: ")
scores = [int(value) for value in entered_scores.split()]

if scores:
    good_scores = get_good_scores(scores)

    print("Средняя оценка:", calculate_average(scores))  # Для ввода 5 3 4 5: 4.25.
    print("Оценок не ниже четырёх:", len(good_scores))  # Для ввода 5 3 4 5: 3.
    print("Сами оценки:", good_scores)  # Для ввода 5 3 4 5: [5, 4, 5].
else:
    print("Оценки не введены")  # Если нажать Enter без чисел.
```

В обоих файлах выводятся значения специальных имён `__name__` и `__file__`. `__name__` показывает, под каким именем выполняется модуль. При прямом запуске файла его значение равно строке `"__main__"`; при импорте `other_file.py` — строке `"other_file"`. `__file__` содержит путь к соответствующему `.py`-файлу. Значение пути зависит от расположения файлов и способа запуска.

Откройте командную строку в каталоге с обоими файлами и выполните команды по очереди:

```cmd
python other_file.py
python main.py
```

При запуске `main.py` введите, например, `5 3 4 5`. Сначала появятся значения из импортируемого `other_file.py`, затем значения из `main.py`. Условие `if __name__ == "__main__":` в `other_file.py` позволяет выполнять его проверочные вычисления только при прямом запуске этого файла. Строки вывода `__name__` и `__file__` находятся вне условия, поэтому выполняются и при импорте. Ввод в `main.py` тоже расположен на верхнем уровне: если импортировать `main.py` из третьего файла, запрос оценок выполнится.

## `__file__` и переход к путям

При выполнении кода из обычного `.py`-файла доступно специальное имя `__file__`: оно содержит путь к файлу, из которого загружен модуль. Путь может быть относительным или абсолютным. В интерактивной консоли и у некоторых модулей без обычного файла `__file__` отсутствует.

Чтобы обратиться к файлу данных рядом со скриптом, сначала найдём каталог самого скрипта:

```python
from pathlib import Path

script_directory = Path(__file__).resolve().parent
data_path = script_directory / "data" / "measurements.txt"
```

Разберём выражение `Path(__file__).resolve().parent` слева направо:

| Часть выражения | Значение |
| --- | --- |
| `__file__` | Строка с путём к текущему `.py`-файлу. Например, `C:\lessons\main.py`. |
| `Path` | Класс из стандартного модуля `pathlib`, представляющий путь как объект. Его нужно импортировать строкой `from pathlib import Path`. |
| `Path(__file__)` | Создаёт объект пути из значения `__file__`. Само создание объекта ещё не читает файл. |
| `.resolve()` | Возвращает новый абсолютный путь, устраняет компоненты `..` и разрешает символические ссылки, если они есть. Скобки нужны, потому что это вызов метода. |
| `.parent` | Возвращает родительский каталог полученного пути. Скобки не нужны: это свойство объекта, а не метод. |

Если `main.py` находится по пути `C:\lessons\main.py`, итогом будет путь к каталогу `C:\lessons`. Точки между частями выражения означают, что следующая операция выполняется над результатом предыдущей. Итоговое значение `script_directory` остаётся объектом `Path`.

### Как меняется путь после `resolve()`

Предположим, командная строка открыта в каталоге занятия. Выражение ниже специально добавляет в путь компонент `..`, означающий переход к родительскому каталогу:

```python
from pathlib import Path

path = Path("data") / ".." / "data" / "measurements.txt"
print(path)  # Windows: data\..\data\measurements.txt; Linux: data/../data/measurements.txt.
print(path.resolve())  # Абсолютный путь к data/measurements.txt без компонента "..".
```

При указанных ниже рабочих каталогах путь будет выглядеть так:

| Система и рабочий каталог | До `resolve()` | После `resolve()` |
| --- | --- | --- |
| Windows: `C:\lessons` | `data\..\data\measurements.txt` | `C:\lessons\data\measurements.txt` |
| Linux: `/home/student/lessons` | `data/../data/measurements.txt` | `/home/student/lessons/data/measurements.txt` |

Часть `data/..` означает: войти в каталог `data` и вернуться обратно. В результате остаётся путь к тому же файлу, но после `resolve()` он абсолютный и не содержит `..`. Если на пути есть символические ссылки, `resolve()` также переходит к их целям. При другом рабочем каталоге абсолютный путь в результате будет другим.

Вторая строка примера, `script_directory / "data" / "measurements.txt"`, добавляет к пути каталога части `data` и `measurements.txt`. Оператор `/` у объектов `Path` собирает путь; он не выполняет деление и не создаёт файл. `Path.cwd()` возвращает текущий рабочий каталог процесса, который может отличаться от каталога скрипта. Поэтому путь от `__file__` удобен для данных, хранящихся рядом с программой.

## Основные действия с `pathlib`

`Path` представляет путь как объект. Через него удобно составлять пути, проверять существование файлов и каталогов, создавать каталоги, читать и записывать текст. Для текстовых файлов явно задаём UTF-8.

`Path` особенно полезен, если один и тот же код запускают в Windows и Linux. В Windows части пути обычно разделяются `\`, а в Linux — `/`. Класс `Path` использует правила текущей системы, поэтому выражение `script_directory / "data" / "measurements.txt"` работает на обеих платформах без ручной подстановки разделителя. Для переносимости не следует прописывать в программе фиксированный путь с буквой диска Windows или путь к домашнему каталогу конкретного компьютера; лучше строить путь из `__file__` и относительных частей. [Документация `pathlib`](https://docs.python.org/3/library/pathlib.html).

```python
from pathlib import Path

script_directory = Path(__file__).resolve().parent
data_directory = script_directory / "data"
data_directory.mkdir(exist_ok=True)

data_path = data_directory / "measurements.txt"
if data_path.is_file():
    text = data_path.read_text(encoding="utf-8")
    print(text, end="")  # 10, 12 и 15 — каждое число на отдельной строке.

    copy_path = data_directory / "measurements_copy.txt"
    copy_path.write_text(text, encoding="utf-8")
    print(copy_path.name)  # measurements_copy.txt.
```

`mkdir(exist_ok=True)` создаёт каталог `data`, если его ещё нет, и не выдаёт ошибку, если каталог уже существует. `read_text()` читает содержимое готового файла измерений, а `write_text()` сохраняет его копию. `is_file()` проверяет, существует ли по этому пути обычный файл. Параметр `end=""` в `print()` предотвращает добавление лишнего перевода строки, потому что текст файла уже заканчивается переводом строки.

## Знакомство с NumPy

NumPy — сторонняя библиотека Python для численных вычислений. Её основа — массив `ndarray`, в котором элементы имеют общий тип данных. Библиотека предоставляет функции для создания массивов, вычислений над ними и обработки числовых данных. В отличие от `pathlib`, NumPy не входит в стандартную библиотеку Python: её устанавливают отдельно в используемое виртуальное окружение. [Официальное введение в NumPy](https://numpy.org/doc/stable/user/absolute_beginners.html).

Вычислительное ядро NumPy написано на C. Когда мы применяем готовую операцию ко всему массиву, обработка его элементов обычно идёт в скомпилированном коде без отдельного прохода циклом Python по каждому числу. Поэтому для больших массивов такие вычисления часто значительно быстрее ручного цикла Python. Само по себе использование NumPy не гарантирует ускорения любой программы: для маленьких наборов данных создание массива тоже требует времени. [О производительности NumPy](https://numpy.org/).

Если NumPy ещё не установлена, в командной строке с активированным виртуальным окружением выполните:

```cmd
python -m pip install numpy
```

Библиотеку обычно импортируют под коротким именем `np`:

```python
import numpy as np
```

Далее все примеры с массивами предполагают, что эта строка уже выполнена. Префикс `np.` показывает, что функция или константа взята из NumPy.

## Зачем NumPy, если есть списки

Список Python может хранить значения разных типов. Массив NumPy удобен, когда есть набор однотипных чисел и нужно выполнить над всеми элементами одинаковое вычисление. Оператор `*` для списка повторяет его элементы, а для массива умножает каждый элемент на число:

```python
numbers_list = [10, 12, 15]
numbers_array = np.array([10, 12, 15])

print(numbers_list * 2)   # [10, 12, 15, 10, 12, 15]
print(numbers_array * 2)  # [20 24 30]
print(numbers_array + 3)  # [13 15 18]
```

Операции над целым массивом без явного цикла Python называют векторизованными. Начнём с одномерных массивов; для работы с несколькими осями потребуется отдельно разобраться в форме массива.

### Создание массива и его свойства

```python
values = np.array([10, 12, 15])

print(values.dtype)  # Целочисленный тип, например int64; зависит от платформы.
print(values.shape)  # (3,).
print(values.ndim)   # 1.
print(values.size)   # 3.
```

| Свойство | Что показывает |
| --- | --- |
| `dtype` | Тип элементов массива. |
| `shape` | Форму массива; для трёх элементов в одномерном массиве — `(3,)`. |
| `ndim` | Количество измерений; для одномерного массива — `1`. |
| `size` | Общее количество элементов. |

Массив можно создать из готовых значений или сгенерировать. `np.arange(start, stop, step)` строит последовательность с заданным шагом, не включая `stop`. `np.linspace(start, stop, num)` создаёт `num` равномерно расположенных значений и по умолчанию включает обе границы. `np.zeros(count)` создаёт массив из `count` нулей.

```python
print(np.array([2, 4, 6]))   # [2 4 6].
print(np.arange(0, 10, 2))   # [0 2 4 6 8].
print(np.linspace(0, 1, 5))  # [0.   0.25 0.5  0.75 1.  ].
print(np.zeros(4))           # [0. 0. 0. 0.].
```

## Индексация, срезы и отбор по условию

Индексы и срезы одномерного массива похожи на индексы и срезы списка. Отбор по условию создаёт массив логических значений, которым можно выбрать элементы исходного массива.

```python
values = np.array([2, 5, 8, 11])

print(values[0])                      # 2.
print(values[1:3])                    # [5 8].
print(values[values >= 6])           # [ 8 11].
print(np.count_nonzero(values >= 6))  # 2.
```

С помощью `np.sum()`, `np.mean()`, `np.min()`, `np.max()` и `np.std()` можно получить сумму, среднее значение, минимум, максимум и стандартное отклонение элементов массива:

```python
print(np.sum(values))   # 26.
print(np.mean(values))  # 6.5.
print(np.min(values))   # 2.
print(np.max(values))   # 11.
print(np.std(values))   # Примерно 3.3541.
```

Здесь `values` — одномерный массив из предыдущего примера. Параметр `axis` для таких вычислений пока не требуется.

## Математические функции для массивов

Математические функции NumPy применяются к каждому элементу массива. `np.sin()` и `np.cos()` принимают углы в радианах. Если углы заданы в градусах, сначала переведите их через `np.deg2rad()`:

```python
angles_degrees = np.array([0, 30, 45, 90])
angles_radians = np.deg2rad(angles_degrees)

print(np.sin(angles_radians))  # Примерно [0.    0.5   0.707 1.   ].
print(np.cos(angles_radians))  # Примерно [1.    0.866 0.707 0.   ].
```

Последний элемент результата `np.cos()` может выглядеть как очень маленькое число около нуля, например `6.123234e-17`: это погрешность вычислений с числами с плавающей точкой. Так же поэлементно работают `np.abs()` для модуля числа и `np.sqrt()` для квадратного корня. Константа `np.pi` и функция `np.linspace()` позволяют создать набор углов для вычислений, например `np.linspace(0, 2 * np.pi, 5)`.

## Данные из файла

Текстовый файл с числами можно загрузить в массив NumPy. В файле [data/measurements.txt](data/measurements.txt) каждое число занимает отдельную строку:

```text
10
12
15
```

Путь к файлу собирается относительно текущего `.py`-файла:

```python
from pathlib import Path
import numpy as np

data_path = Path(__file__).resolve().parent / "data" / "measurements.txt"
measurements = np.loadtxt(data_path)

print(measurements)                     # [10. 12. 15.].
print(np.mean(measurements))            # Примерно 12.333333333333334.
print(measurements[measurements > 11])  # [12. 15.].
```

`np.loadtxt()` читает числовые данные из файла, а выражение `measurements > 11` создаёт логическую маску для выбора значений выше порога. Для сохранения числового массива в текстовый файл используется `np.savetxt(output_path, measurements)`, где `output_path` — путь к файлу результата.

## Обход файлов в каталоге

Метод `Path.iterdir()` позволяет перебрать элементы непосредственно внутри каталога. Каждый полученный элемент — объект `Path`: это может быть файл или вложенный каталог. Метод `is_file()` помогает выбрать файлы, а свойства `name`, `stem` и `suffix` позволяют работать с их именами.

| Выражение для `sensor_a.txt` | Результат |
| --- | --- |
| `path.name` | `sensor_a.txt` — имя файла вместе с расширением. |
| `path.stem` | `sensor_a` — имя без последнего расширения. |
| `path.suffix` | `.txt` — последнее расширение. |
| `path.is_file()` | `True`, если по пути находится обычный файл. |

```python
from pathlib import Path

data_directory = Path(__file__).resolve().parent / "data" / "series"
example_path = data_directory / "sensor_a.txt"

print(example_path.name)     # sensor_a.txt.
print(example_path.stem)     # sensor_a.
print(example_path.suffix)   # .txt.
print(example_path.is_file())  # True, если файл из комплекта находится на месте.

for path in data_directory.iterdir():
    print(path.name)  # Имена четырёх файлов .txt и README.md; порядок не гарантирован.
```

`iterdir()` не заходит во вложенные каталоги. В папках с заданиями лежит также `README.md`, который не содержит числовых данных. При обработке нужно проверять и тип элемента, и расширение: файл `.md` нельзя передавать в `np.loadtxt()` как набор чисел. Порядок элементов при обходе не гарантирован; если для отчёта нужен постоянный порядок, пути можно отсортировать функцией `sorted()`.

## Самостоятельное задание 1. Сравнение серий измерений

В каталоге [data/series](data/series/README.md) находятся четыре файла `.txt`. Каждый файл содержит одну серию измерений, по одному числу в строке; число измерений в сериях различается. Напишите программу в отдельном `.py`-файле рядом с каталогом `data`.

1. Запросите у пользователя числовой порог, одинаковый для всех серий.
2. Обойдите элементы каталога `data/series` через `Path.iterdir()`. Обработайте только обычные файлы с расширением `.txt`; `README.md` пропустите.
3. Для каждого файла загрузите данные через `np.loadtxt()` и вычислите количество измерений, минимум, максимум, среднее значение, стандартное отклонение и количество значений строго выше заданного порога.
4. Сравните серии между собой: определите файл с наибольшим средним значением и файл с наименьшим стандартным отклонением.
5. Создайте отдельный каталог `results` и сохраните в `results/series_report.txt` порог, результаты по каждому файлу и результаты сравнения. Повторный запуск программы должен обновлять отчёт, не обрабатывая его как входной файл.

В отчёте указывайте имена входных файлов, чтобы было понятно, к какой серии относятся вычисленные значения. Не предполагайте, что во всех файлах одинаковое число строк.

## Самостоятельное задание 2. Обработка наборов углов

В каталоге [data/angles](data/angles/README.md) находятся четыре файла `.txt` с углами в градусах, по одному значению в строке. Напишите отдельную программу рядом с каталогом `data`.

1. Обойдите элементы каталога `data/angles` через `Path.iterdir()`. Обработайте только обычные файлы `.txt`; `README.md` пропустите.
2. Для каждого файла загрузите углы через `np.loadtxt()`, переведите их в радианы и вычислите массивы значений синуса и косинуса.
3. Создайте каталог `results/angles`. Для входного файла `set_a.txt` сохраните массивы в `set_a_sin.txt` и `set_a_cos.txt` внутри этого каталога. Для других входных файлов получите имена результатов через свойство `stem`. Сохраняйте числовые массивы с помощью `np.savetxt()`.
4. Для каждого входного файла найдите наибольший угол и количество углов, у которых синус строго больше `0.6`.
5. Сохраните в `results/angles_report.txt` результаты по каждому набору и имя файла, в котором нашлось больше всего углов с синусом выше `0.6`.

В обоих заданиях входные данные находятся в `data`, а результаты — в `results`. Так программа может повторно обойти входной каталог, не пытаясь прочитать созданные ею файлы как новые исходные данные.
