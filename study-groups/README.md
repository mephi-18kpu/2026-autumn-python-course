# Успеваемость студентов

Эта директория может использоваться для публикации таблиц успеваемости студентов в рамках курса. Ведение таких таблиц в GitHub является предлагаемой возможностью, а не обязанностью преподавателя.

Если преподаватель решает использовать эту возможность, он обязан уведомить студентов о публикации таблиц, расположении файлов и применяемых обезличенных идентификаторах. Если таблицы в GitHub вестись не будут, директорию `study-groups/` следует удалить из репозитория, чтобы её наличие не вводило преподавателей и студентов в заблуждение.

Для каждой учебной группы рекомендуется создавать отдельный Markdown-файл по шаблону `<номер-группы>.md`, например `b24-601.md`. Вместо ФИО используется обезличенный идентификатор вида `<номер-группы>_student_<номер-студента-в-группе>`, например `b24-601_student_07`.

Таблицы не должны содержать связь идентификаторов с ФИО, аккаунтами GitHub и другими персональными данными. Подробные правила приведены в [инструкции по ведению учебного курса](https://github.com/mephi-18kpu/common-manuals/blob/master/teachers/course-workflow.md#6-публикация-списков-и-результатов).
