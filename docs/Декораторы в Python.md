# Декораторы в Python

Декоратор позволяет изменить то, что происходит при вызове функции, сохранив её тело. Например, если нужно измерить время работы нескольких функций, код замера можно написать один раз и применить один и тот же декоратор к каждой из них. Сами функции по-прежнему выполняют свою основную задачу, а замер берёт на себя обёртка.

На занятии напишем два декоратора. Первый запустит функцию один раз, выведет время работы и вернёт её результат. Второй запустит функцию несколько раз и соберёт результаты в список.

Запись с `@` уже встречалась в занятии про векторы, например в `@staticmethod` и `@property`. Чтобы понять, что происходит при декорировании, начнём с обычного вызова функции. [Векторы и траектории в Python](Векторы%20и%20траектории%20в%20Python.md#методы-и-свойства)

## Что делает запись с `@`

Напишем декоратор, который пока ничего не добавляет к вызову. Он принимает исходную функцию, создаёт вложенную функцию `wrapper` и возвращает её. Такую вложенную функцию называют **обёрткой**.

```python
def empty_decorator(function):
    def wrapper():
        return function()

    return wrapper


def get_number():
    return 124


get_number = empty_decorator(get_number)
print(get_number())
```

При присваивании `get_number = empty_decorator(get_number)` декоратор получает исходную функцию и возвращает вложенную функцию `wrapper`. После присваивания имя `get_number` указывает на функцию `wrapper`. Именно она служит обёрткой. Когда мы вызываем `get_number()`, обёртка вызывает исходную функцию и возвращает `124`.

Запись с `@empty_decorator` выполняет то же оборачивание. В этом варианте достаточно написать декоратор над определением функции.

```python
@empty_decorator
def get_number():
    return 124


print(get_number())
```

При декорировании выполняется `return wrapper`, который возвращает саму функцию. При последующем вызове `get_number()` выполняется `return function()`, который возвращает результат исходной функции. Обёртка сохраняет доступ к `function` после завершения `empty_decorator()`. Это пример **замыкания**.

## Декоратор для замера времени

Возьмём ту же обёртку и вызовем `time.time()` до и после вызова исходной функции. Разность двух показаний даёт длительность вызова в секундах по системным часам. Добавим `time.sleep(1.5)`, чтобы задержка была заметна. Обёртка выведет время, а внешний `print()` выведет результат `124`. [Документация `time.time()`](https://docs.python.org/3/library/time.html#time.time)

```python
import time


def timer(function):
    def wrapper():
        start_time = time.time()
        result = function()
        elapsed = time.time() - start_time
        print(f"Время выполнения: {elapsed:.3f} с")
        return result

    return wrapper


@timer
def get_number():
    time.sleep(1.5)
    return 124


print(get_number())
```

## Декоратор для функции с аргументами

Добавим в `get_number` параметр `sleep_time`, чтобы задавать длительность паузы при вызове. Если оставить прежнюю версию `timer` и вызвать `get_number(sleep_time=0.2)`, Python выдаст `TypeError`. Аргумент попадает в `wrapper()`, а у неё пока нет параметров.

Используем знакомый приём. В определении обёртки `*args` собирает позиционные аргументы в кортеж, а `**kwargs` собирает именованные аргументы в словарь. При вызове `function(*args, **kwargs)` обёртка распаковывает их и передаёт исходной функции. [Параметры функций, `*args` и `**kwargs`](Параметры%20функций%2C%20args%20и%20kwargs.md)

```python
import time


def timer(function):
    def wrapper(*args, **kwargs):
        start_time = time.time()
        result = function(*args, **kwargs)
        elapsed = time.time() - start_time
        print(f"Время выполнения: {elapsed:.3f} с")
        return result

    return wrapper


@timer
def get_number(sleep_time=1.5):
    time.sleep(sleep_time)
    return 124


print(get_number(sleep_time=0.2))
```

В этом вызове `args` будет пустым кортежем, а в `kwargs` будет пара `"sleep_time": 0.2`. Попробуйте передать то же значение позиционно через `get_number(0.2)`.

## Декоратор с параметром `@repeat(n)`

Напишем декоратор, который при одном вызове обёртки запускает исходную функцию `n` раз. Каждый раз он передаёт ей те же аргументы и добавляет результат в список. Так, `repeat(0)` возвращает декоратор, чья обёртка выдаст пустой список. Отрицательное число повторов вызовет `ValueError` при вызове `repeat(n)`.

Без `@` запись выглядит как `get_number = repeat(3)(get_number)`. Здесь три функции выполняются в разные моменты.

1. `repeat(3)` получает число повторов и возвращает `decorator`.
2. `decorator(get_number)` получает исходную функцию и возвращает `wrapper`.
3. При вызове `get_number(sleep_time=0.2)` обёртка получает аргументы, выполняет цикл и возвращает список результатов.

```python
import time


def repeat(n):
    if n < 0:
        raise ValueError("Число повторов должно быть неотрицательным")

    def decorator(function):
        def wrapper(*args, **kwargs):
            results = []
            for _ in range(n):
                results.append(function(*args, **kwargs))
            return results

        return wrapper

    return decorator


@repeat(3)
def get_number(sleep_time=1.5):
    time.sleep(sleep_time)
    return 124


print(get_number(sleep_time=0.2))
```

Программа выведет `[124, 124, 124]`. Что выведет тот же вызов, если заменить `@repeat(3)` на `@repeat(0)`? Почему список создаётся внутри `wrapper`?

## Самостоятельное задание. Логирование вызова функции

Напишите декоратор `@log_call`. Перед вызовом исходной функции выведите её имя, позиционные и именованные аргументы. Затем вызовите исходную функцию один раз, передайте ей все аргументы и верните её результат.

Если параметр декоратора называется `function`, имя полученной функции можно взять через `function.__name__`. Например, для функции `add` это будет строка `"add"`. Позиционные аргументы уже собраны в `args`, а именованные в `kwargs`.

```python
@log_call
def add(a, b):
    return a + b


print(add(2, b=3))
```

Ожидаемый вывод

```text
add: args=(2,), kwargs={'b': 3}
5
```
