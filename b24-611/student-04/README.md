# Рабочая директория `student-04`

Директория предназначена для постоянной работы студента группы `b24-611` с идентификатором `student-04`.

## Параметры

- Группа: `b24-611`.
- Идентификатор студента: `student-04`.
- Рабочая ветка: `student/b24-611/student-04`.

## Правила работы

Размещайте учебные файлы только в этой директории, если преподаватель не указал иной порядок. Не изменяйте директории и ветки других студентов.

Для отчётных заданий используйте отдельно подготовленные ветки `student-submission/<работа>/b24-611/student-04` и следуйте инструкции преподавателя по созданию Pull Request.
