# `venv`, ввод данных и `if-elif-else`

## Что получится после занятия

Вы создадите отдельное окружение проекта и программу, которая:

- спрашивает имя и количество баллов;
- преобразует введённые баллы в число;
- сравнивает число с двумя границами;
- выбирает одну из трёх ветвей;
- выводит результат с помощью f-строки.

## Зачем проекту виртуальное окружение

На компьютере может быть глобальная установка Python, доступная разным проектам. Если устанавливать в неё все сторонние пакеты, проекты начинают зависеть от общего набора библиотек.

Это неудобно:

- проекты могут требовать разные версии одного пакета;
- обновление пакета для нового проекта может нарушить старый;
- программа может незаметно использовать глобальный пакет, которого нет на другом компьютере;
- терминал и редактор могут запускать разные установки Python;
- становится непонятно, какие пакеты действительно нужны проекту.

Виртуальное окружение создаётся на основе выбранной установки Python. Внутри `.venv` находятся ссылка или копия исполняемого файла Python, отдельный каталог сторонних пакетов, скрипты активации и файл `pyvenv.cfg`.

Пример структуры проекта:

```text
first-task/
├── .venv/
├── functions_file.py
├── main.py
└── requirements.txt
```

- `.venv` — окружение проекта и установленные пакеты;
- `functions_file.py` — функции, вынесенные из основного файла;
- `main.py` — точка входа в программу;
- `requirements.txt` — список пакетов, по которому окружение можно восстановить.

`.venv` можно удалить и создать заново. В ней не хранят исходный код и её не переносят между компьютерами.

## Проверка Python

Откройте Windows `cmd` в папке проекта:

```cmd
python --version
python -c "import sys; print(sys.executable)"
```

- `python --version` показывает версию Python;
- `sys.executable` показывает путь к фактически запущенному интерпретатору;
- `-c`, сокращение от `command`, выполняет переданную строку Python-кода.

Если команда `python` не настроена, попробуйте:

```cmd
py --version
```

## Создание `.venv`

Создайте окружение в корне проекта:

```cmd
python -m venv .venv
```

Команда читается так:

- `python` — запустить выбранный интерпретатор;
- `-m venv` — выполнить стандартный модуль `venv`;
- `.venv` — создать окружение в этой папке.

В Windows также можно использовать:

```cmd
py -m venv .venv
```

## Активация окружения

В Windows `cmd`:

```cmd
.venv\Scripts\activate.bat
```

В Linux и macOS:

```bash
source .venv/bin/activate
```

После активации приглашение командной строки обычно выглядит так:

```text
(.venv) C:\Dir\Path>
```

Активация изменяет поиск команд только в текущем терминале. После неё команда `python` должна указывать на интерпретатор окружения.

Проверьте путь:

```cmd
python -c "import sys; print(sys.executable)"
```

В пути должна присутствовать `.venv` текущего проекта. Префикс `(.venv)` является подсказкой, но полный путь — более надёжная проверка.

Выйти из окружения:

```cmd
deactivate
```

Если PowerShell сообщает, что выполнение сценариев запрещено, то необходимо изменить политику выполнения сценариев. Подробнее [по ссылке](https://remontka.pro/execution-of-scripts-disabled-powershell/).  
Также можете попробовать открыть `cmd` и использовать `activate.bat`.

## Ввод данных: `input()` и `int()`

Функция `input()` показывает приглашение, ждёт ввод пользователя и возвращает строку типа `str`:

```python
score = input("Баллы: ")
print(type(score))  # str
```

Даже если пользователь вводит `75`, программа сначала получает строку `"75"`.

Для числовых операций строку нужно преобразовать:

```python
score = int(input("Баллы: "))
print(type(score))  # int
```

Последовательность преобразования:

```text
клавиатура → input() → str → int() → int
```

Если строка не записана как целое число, `int()` завершит программу с `ValueError`. Обработку таких ошибок вы изучите отдельно.

## Операторы сравнения

Результат любого сравнения — логическое значение `True` или `False`:

```python
print(75 >= 60)  # True
print(59 >= 60)  # False
```

Основные операторы:

| Оператор | Значение | Пример |
|---|---|---|
| `>` | больше | `score > 60` |
| `<` | меньше | `temperature < 0` |
| `>=` | больше или равно | `score >= 60` |
| `<=` | меньше или равно | `count <= 10` |
| `==` | равно | `number == 0` |
| `!=` | не равно | `number != 0` |

`=` присваивает значение переменной, а `==` сравнивает два значения.

## Выбор ветви с помощью `if-elif-else`

```python
if score >= 60:
    print("Зачёт")
elif score >= 40:
    print("Нужна доработка")
else:
    print("Незачёт")
```

Python проверяет условия сверху вниз:

1. Если условие `if` истинно, выполняется его ветвь.
2. Иначе проверяется условие `elif`.
3. Если оба условия ложны, выполняется `else`.
4. После выбора одной ветви остальные пропускаются.

Обратите внимание:

- после `if`, `elif` и `else` ставится двоеточие;
- после `elif` обязательно записывается условие;
- команды внутри ветвей имеют отступ в четыре пробела;
- `if`, `elif` и `else` находятся на одном уровне отступа.

Отступ является частью синтаксиса Python.

## f-строки

f-строка позволяет подставлять значения переменных и выражений внутрь текста:

```python
student_name = "Анна"
score = 75
print(f"{student_name}: {score} баллов")
```

Результат:

```text
Анна: 75 баллов
```

- `f` перед кавычкой сообщает Python, что строка форматируемая;
- выражения внутри `{}` вычисляются и подставляются в строку;
- не нужно соединять части сообщения через `+` и отдельно вызывать `str()`.

## Первая программа с вводом

Создайте файл `main.py`:

```python
"""Приветствие пользователя по имени."""

# System imports

# External imports

# User imports

#############################################

student_name = input("Введите имя: ")
print(f"Здравствуйте, {student_name}!")
```

В начале файла находится строка документации модуля. Ниже оставлены три раздела для системных, сторонних и пользовательских импортов. В этой программе импорты пока не нужны.

Запустите программу:

```cmd
python main.py
```

Пример работы:

```text
Введите имя: Анна
Здравствуйте, Анна!
```

## Итоговая программа

```python
"""Определение результата работы по количеству баллов."""

# System imports

# External imports

# User imports

#############################################

PASSING_SCORE = 60
REVISION_SCORE = 40

student_name = input("Введите имя студента: ")
score = int(input("Введите количество баллов: "))

if score >= PASSING_SCORE:
    print(f"{student_name}, работа зачтена.")
elif score >= REVISION_SCORE:
    missing_score = PASSING_SCORE - score
    print(f"{student_name}, до зачёта не хватает: {missing_score}.")
else:
    print(f"{student_name}, работа не зачтена.")
```

`PASSING_SCORE` и `REVISION_SCORE` записаны заглавными буквами, потому что это константы: во время работы программы границы не меняются.

Условия расположены от более строгого к менее строгому. Проверка `score >= 40` выполняется только после того, как проверка `score >= 60` дала `False`.

## Проверка всех ветвей

Одного успешного запуска недостаточно. Перед запуском предскажите выбранную ветвь, затем сравните ожидание с результатом.

| Баллы | Ветвь | Ожидаемый результат |
|---:|---|---|
| `75` | `if` | работа зачтена |
| `60` | `if` | точная граница зачёта |
| `59` | `elif` | нужна доработка |
| `40` | `elif` | точная граница доработки |
| `39` | `else` | работа не зачтена |
| `0` | `else` | работа не зачтена |

Значения `60`, `59`, `40` и `39` особенно важны: они проверяют обе границы и порядок условий.

## Если программа не запускается

### `python` не найден

Проверьте в Windows `cmd`:

```cmd
py --version
```

### `ValueError`

В `int()` попала строка неподходящего формата. Перезапустите программу и введите целое число, например `75`, а не `семьдесят пять` или `75.5`.

### `SyntaxError`

Проверьте двоеточия после `if`, `elif` и `else`.

### `IndentationError`

Проверьте одинаковые отступы внутри ветвей. Не смешивайте табуляцию и пробелы.

Traceback обычно читают снизу вверх: последняя строка называет тип ошибки.
