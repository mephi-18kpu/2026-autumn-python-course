# Введение в ООП в Python

**Объектно-ориентированное программирование (ООП)** — способ организации программы вокруг объектов. Объект может хранить данные, которые описывают его состояние, и предоставлять методы для работы с ними. Объекты могут обращаться к методам друг друга. При таком устройстве можно определить, какая часть программы отвечает за конкретные данные и допустимые изменения этих данных.

Основные принципы ООП описывают, как моделировать объекты и как с ними работать.

- **Абстракция** помогает выделить свойства и операции, которые важны для задачи. Для расчёта площади фигуры нужны её размеры. Цвет может понадобиться при отрисовке.
- **Инкапсуляция** позволяет управлять состоянием объекта через предусмотренные операции. Например, метод изменения размеров может проверить их перед сохранением.
- **Наследование** позволяет создать класс на основе существующего, использовать его методы и переопределять нужное поведение.
- **Полиморфизм** позволяет одинаково вызвать операцию у объектов разных типов. Каждый объект выполняет её по правилам своего типа.

Программа получает несколько геометрических фигур и выводит площадь каждой. Для прямоугольника нужны ширина и высота, для круга нужен радиус. Формулы различаются, но действие для любой фигуры одно и то же — получить её площадь.

## Данные и поведение

В Си размеры прямоугольника можно хранить в структуре и передавать её адрес в функцию, которая вычисляет площадь.

```c
struct Rectangle {
    double width;
    double height;
};

double rectangle_area(const struct Rectangle *rectangle)
{
    return rectangle->width * rectangle->height;
}
```

При вызове `rectangle_area(&rectangle)` адрес прямоугольника передаётся функции явно. В Python можно определить класс `Rectangle` и вызвать `rectangle.area()`. Метод получит этот объект и возьмёт размеры из него. Данные объекта образуют его **состояние**, а операции над ним описывают его **поведение**. Класс определяет тип объекта и задаёт методы для его экземпляров. [Документация Python о классах](https://docs.python.org/3/tutorial/classes.html)

При выборе между классом и функцией полезно посмотреть, кто хранит данные и что с ними происходит. В Python для разового расчёта по двум числам достаточно функции `rectangle_area(width, height)`. Класс становится полезен, когда один прямоугольник нужно хранить между вызовами, проверять при изменении и передавать другим частям программы вместе с операциями, которые он поддерживает.

## Класс и экземпляр

Определим класс и создадим два прямоугольника.

```python
class Rectangle:
    """Прямоугольник с заданными шириной и высотой."""

    def __init__(self, width: float, height: float) -> None:
        """Задать размеры прямоугольника.

        Args:
            width: Ширина.
            height: Высота.

        Raises:
            ValueError: Один из размеров не положителен.
        """
        if not (width > 0 and height > 0):
            raise ValueError("Ширина и высота должны быть положительными")

        self._width: float = width
        self._height: float = height

    def area(self) -> float:
        """Вернуть площадь прямоугольника."""
        return self._width * self._height


first_rectangle = Rectangle(3, 4)
second_rectangle = Rectangle(2, 5)

print(first_rectangle.area())
print(second_rectangle.area())
```

При вызове `Rectangle(3, 4)` Python создаёт экземпляр и вызывает `__init__()` для его инициализации. Параметр `self` получает созданный объект. Присваивания в `__init__()` сохраняют ширину и высоту в атрибутах этого экземпляра.

Вызов `first_rectangle.area()` передаёт первый прямоугольник в `self`. Для этого класса вызов можно записать явно как `Rectangle.area(first_rectangle)`. При вызове `second_rectangle.area()` тот же метод получает второй объект, поэтому использует другие размеры. Программа выведет `12` и `10`. [Документация Python о методах](https://docs.python.org/3/tutorial/classes.html#method-objects)

## Абстракция

**Абстракция** — выделение свойств и операций, существенных для задачи. При разработке класса сначала определяют, какие данные нужны программе и какие операции будут доступны вызывающему коду. Уровень детализации зависит от того, какую задачу решает программа.

Абстракцию используют при моделировании предметной области. Например, при расчёте стоимости доставки у посылки важны вес и габариты. Для поиска той же посылки на складе нужны её номер и место хранения. В каждом случае модель включает сведения, с которыми работает соответствующая часть программы.

В примере с фигурами для расчёта нужны размеры каждой фигуры и операция `area()`. Код, который выводит площади, пользуется этой операцией. Формула расчёта определяется в классе каждой фигуры.

## Инкапсуляция

**Инкапсуляция** объединяет состояние объекта и операции над ним. Класс предоставляет методы, через которые остальная программа работает с объектом. Эти методы проверяют данные и поддерживают правила, которые должны соблюдаться в любом допустимом состоянии.

Инкапсуляцию применяют там, где данные можно менять только с учётом определённых условий. Например, корзина интернет-магазина предоставляет методы добавления и удаления товара. Метод удаления проверяет количество единиц товара, чтобы после операции оно не стало отрицательным.

Прямоугольник должен иметь положительные размеры. `__init__()` проверяет их при создании, а дальнейшие изменения можно выполнять через методы с такими же правилами.

Добавим операцию масштабирования `scale(factor)`. Вызывающему коду достаточно передать коэффициент. Метод проверяет, что он положительный, и умножает обе стороны на одно число. Так сохраняются пропорции фигуры. Если коэффициент непригоден, метод возбуждает `ValueError` до изменения размеров.

Префикс `_` в `_width` и `_height` показывает, что эти атрибуты экземпляра предназначены для использования внутри класса. Python позволяет обратиться к ним снаружи. По соглашению вызывающий код пользуется методами `scale()` и `area()`. [Документация Python о внутренних атрибутах](https://docs.python.org/3/tutorial/classes.html#private-variables)

## Наследование и строковое представление

**Наследование** позволяет определить новый класс на основе существующего. Существующий класс называют базовым, а новый — подклассом. Подкласс может использовать методы базового класса, добавлять свои и переопределять унаследованные методы.

Наследование используют, когда новый класс представляет разновидность базового типа. Например, кнопка с иконкой остаётся кнопкой и может унаследовать общий способ обработки нажатия. Подкласс добавляет отрисовку иконки.

Выделим базовый класс `Shape` для геометрических фигур. В нём укажем общую операцию `area()` и определим общую часть строкового представления. Подклассы, например `Rectangle` и `Circle`, вычисляют площадь по своим формулам.

```python
class Shape:
    """Геометрическая фигура, для которой можно вычислить площадь."""

    def area(self) -> float:
        """Запросить площадь у конкретного подкласса.

        Raises:
            NotImplementedError: Подкласс должен определить метод расчёта площади.
        """
        raise NotImplementedError("Подкласс должен определить метод area()")

    def __str__(self) -> str:
        """Вернуть имя типа фигуры."""
        return type(self).__name__
```

Запись `class Rectangle(Shape):` делает `Rectangle` подклассом `Shape`. Собственный `area()` класса `Rectangle` переопределяет одноимённый метод базового класса. `Shape.area()` явно сообщает об ошибке, если конкретная фигура не определила расчёт. [Документация Python о наследовании](https://docs.python.org/3/tutorial/classes.html#inheritance)

Поставьте `Shape` перед определением `Rectangle`, укажите `Shape` в заголовке класса `Rectangle` и добавьте в `Rectangle` этот метод.

```python
    def __str__(self) -> str:
        """Вернуть имя типа и размеры прямоугольника."""
        shape_name = super().__str__()
        return f"{shape_name} ({self._width} × {self._height})"
```

`__init__()` и `__str__()` — специальные методы Python. Вызовы `str(rectangle)` и `print(rectangle)` используют `__str__()` для получения строки. Метод возвращает строку, а `print()` выводит её. В этом примере `super().__str__()` вызывает реализацию `Shape` для того же экземпляра `Rectangle`. Поэтому `type(self).__name__` возвращает `Rectangle`, и итоговая строка для прямоугольника `3 × 4` выглядит как `Rectangle (3 × 4)`. [Документация Python о `__str__()`](https://docs.python.org/3/reference/datamodel.html#object.__str__) · [Документация Python о `super()`](https://docs.python.org/3/library/functions.html#super)

У круга есть собственный размер и своя формула площади. Добавьте `from math import pi` в секцию стандартных импортов.

```python
class Circle(Shape):
    """Круг с заданным радиусом."""

    def __init__(self, radius: float) -> None:
        """Задать радиус круга.

        Args:
            radius: Радиус.

        Raises:
            ValueError: Радиус не положителен.
        """
        if not radius > 0:
            raise ValueError("Радиус должен быть положительным")

        self._radius: float = radius

    def area(self) -> float:
        """Вернуть площадь круга."""
        return pi * self._radius ** 2

    def __str__(self) -> str:
        """Вернуть имя типа и радиус круга."""
        shape_name = super().__str__()
        return f"{shape_name} (радиус {self._radius})"
```

## Полиморфизм

**Полиморфизм** позволяет одному участку кода выполнять одинаковую операцию с объектами разных типов. Вызывающий код использует общее имя метода и рассчитывает на одинаковый смысл операции. Конкретный тип объекта определяет, какая реализация метода выполнится.

Полиморфизм применяют, когда одна часть программы работает с несколькими реализациями операции. Например, сервис уведомлений может вызывать `send(message)` у объектов для отправки электронной почты и SMS. Каждый из них отправляет сообщение своим способом.

Функции `print_all_areas(shapes)` можно передать список разных фигур. В цикле переменная `shape` последовательно получает каждый объект. Python выбирает реализацию `area()` по фактическому типу текущей фигуры.

В теле цикла достаточно одной строки.

```python
print(f"{shape} — площадь {shape.area()}")
```

Подстановка `{shape}` использует строковое представление фигуры с именем типа и размерами. Выражение `shape.area()` вызывает её метод расчёта площади. При вызове `print_all_areas([Rectangle(3, 4), Circle(1)])` ожидается такой вывод.

```text
Rectangle (3 × 4) — площадь 12
Circle (радиус 1) — площадь 3.141592653589793
```
