# Рабочая область аудиторной ветки `b24-611`

Директория предназначена для практической и демонстрационной работы на аудиторных компьютерах.

## Параметры

- Рабочая ветка: `classroom/b24-611`.
- Рабочая директория: `classroom-work/`.

## Правила работы

Ветка является общей для аккаунтов аудиторных компьютеров, имеющих доступ `Write` к репозиторию. Commit идентифицирует рабочее место, но не подтверждает личность пользователя.

Не размещайте здесь пароли, токены, приватные ключи, персональные данные, оценки, закрытые решения и другие конфиденциальные материалы.

Ветка не используется как источник Pull Request в `master`. Изменения, которые требуется включить в материалы курса, сначала проверяются преподавателем и переносятся в его ветку `teacher/<логин>`.
